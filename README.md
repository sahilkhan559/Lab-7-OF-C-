# Lab 7 – Pointers in C++

## Introduction
This lab focuses on understanding pointers in C++. Pointers store memory addresses and allow direct access to variables and dynamic memory.

## Objectives
- Understand pointer basics.
- Use address-of (`&`) and dereference (`*`) operators.
- Swap two numbers using pointers.
- Perform dynamic memory allocation.
- Create and access dynamic arrays.
- Understand pointer arithmetic.

## Lab Tasks

**Task 1 – Pointer Basics**
Declare an integer variable, create a pointer, and display its value and address.

**Task 2 – Swap Numbers**
Swap two numbers using a pointer function.

**Task 3 – Dynamic Memory**
Create an integer dynamically using `new` and display its value.

**Task 4 – Dynamic Array**
Create a dynamic array of 5 integers and print its elements.

**Task 5 – Pointer Arithmetic**
Create an array and access its elements using pointer arithmetic.
